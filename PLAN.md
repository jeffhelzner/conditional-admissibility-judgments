# Project Reboot Plan — Commensuration Closure & E-admissibility as Minimal Extension
(Consolidated 2026-07-23 from planning session. This is the authoritative plan.)

## Thesis
Formalize (Lean 4 + Mathlib) Levi's argument that his indeterminate-probability
generalization of SEU permits non-question-begging change of confirmational commitment.
Core formal claim: commensurability is a closure property on classes of admissibility
judgments; the SEU-representable class lacks it; the E-admissibility class is its
minimal closure. Deliverables: Lean library first; then a Synthese-style paper.

## Key design decisions (all user-approved)
- Fresh start in this repo; git-tag legacy state (`legacy-v1`) then delete old
  src/, test/, reports/ — CONFIRM WITH USER before deletion.
- v1 fixes the decision context (X, K, algebra E, acts A, menus M); only the choice
  function C varies. Heterogeneous contexts + CategoryTheory deferred to v2.
- v1 uses Mathlib ORDER library, not CategoryTheory: ClosureOperator (convex hull,
  commensuration closure), GaloisInsertion (reflection), sSupHom (join-preserving maps).
- Conditioning is internal (supposition slot e); revision C→C' is external.
- Levi vocabulary: commensuration property (factorizability through intermediary),
  commensurable change, commensurating intermediary; strong condition = D "suspends"
  (C ⊆ D ⊇ C' pointwise); weak = "fair hearing" (D(e,m) intersects C(e,m) and C'(e,m)).
  Lean names: Commensurable, Suspends, FairHearing, suspension.
- Change category = zig-zag category generated by contractions 𝓛 (pointwise ⊆ toward
  weaker) and expansions 𝓡 (reverse). No chaotic category.
- Null-supposition policy (Phase 1): C_{{p}}(e,m) with p(e)=0 must NOT default to m
  (breaks join identity M1). Partial C or per-judgment non-null domain — decide in design.

## Mathematical core (the "M" package)
KEY FACT: C_P(e,m) = ⋃_{p∈P} C_{{p}}(e,m) definitionally; pointwise union = join in
the poset J of judgments (pointwise ⊆).
- M0: J has all nonempty joins, computed pointwise.
- M1: Join identity C_P = ⋁_{p∈P} C_{{p}}.
- M2 (HEADLINE): commensurationClosure : Set J → Set J (closure under nonempty joins,
  proved a ClosureOperator, PARAMETRIC in base class). Instance: cc(K_SEU) = K_Eadm.
  Equivalently C_(-) is the unique join-preserving (sSupHom) extension of SEU
  maximization; left-Kan-extension reading is a footnote.
- M3: Commensurating intermediary = join C_{P∪Q}; minimality FREE from universal property.
- Cospan normal form: every 𝓛/𝓡-zig-zag between credal judgments reduces to a
  diameter-≤2 cospan through the join; credal class connected.
- β-corollary (HEADLINE): joins preserve Sen α, destroy β/WARP ⇒ any commensurable class
  containing suitably distinct SEU judgments contains β-violators (dynamic rationality
  entails static WARP-violation).
- Commutation theorem (HEADLINE, uses the e-slot): suppositional conditioning commutes
  with joins/suspension (E-admissibility conditions memberwise, generalized Bayes).
  Ties to Levi's confirmational conditionalization; restores two-dynamics motivation.
- M4 (DEMOTED to statement + partial results): C_{P∪Q} ≠ C_conv(P∪Q) in general
  (compromise acts; SSK 2010 "Coherent choice functions under uncertainty" — choice
  functions distinguish P from conv(P)). Conjecture: convex-representable judgments
  reflective in E-admissibility class (GaloisInsertion), reflection = C_conv(P);
  needs SSK-style identifiability under act/menu richness. Levi suspension =
  join followed by reflection.
- M5 negatives (all from ONE designed witness context, small finite two-prior,
  test/TwoPrior.lean): (a) no SEU intermediary — suspension AND fair-hearing variants;
  (b) strictness C_{P∪Q} < C_conv(P∪Q) (convexity wedge); (c) β-violation witness.
